2Build the transaction, get the digest

    

      

      

    

    
    

    
Copy the digest line above into the terminal where open.sh is waiting for it. It runs this command for you; it is refused unless you allowed signing in step 3. It returns signature and recovery_id to paste below.

    

    
The digest is 32 bytes that stand for this exact transaction: from, to, amount, fee, nonce, network. The Enclave signs those 32 bytes with the key in the vault and returns the signature. It never sees the transaction and never reveals the key.

  


  

    
3Paste the signature, send

    

      

      

    

    
    

    
Before sending, this page checks that the signature belongs to your wallet. If the Enclave signed with the right key, the recovered address matches. Then the network takes it from here. Now take the permission back: ekka gate grant revoke <id>.

  


  

    
What this page uses, and what it never does

    
It loads ethers.js from cdnjs.cloudflare.com and talks to one public Sepolia node (the RPC field above; change it if you run your own). It never asks for a private key, never talks to your Enclave, and never signs anything. It cannot: the only thing on this machine that can produce a signature is the Enclave, and only for a plan a human granted. Everything above is public data plus one signature.
